# パズル全部集合

ブラウザで遊べるパズル・ボードゲーム集です。

**▶ 遊ぶ：https://nw-work-commits.github.io/puzzle-collection/**

- 数独・カックロ・スリザーリンク・倉庫番・ラッシュアワーなどのパズル
- 五目ならべ・チェス・将棋・囲碁は CPU と対戦（強さ3段階）、1台で「ふたりで」も
- テトリス・ぷよ・スイカなどの落ちもの
- オンライン対戦：片方が部屋を作り、もう片方が4けたのコードで入る

問題はすべて自動生成です。答えが1つに決まるものだけを出す、完成形から崩して必ず解けるようにする、
全部の手を調べて最短手数を求める、といった作り方をパズルごとに使い分けています。

オンライン対戦は、端末どうしを直接つなぎます（WebRTC）。つなぐときの仲介だけ、外部の無料サービス
PeerJS を使います。会社や学校などのネットワークでは、つながらないことがあります。
